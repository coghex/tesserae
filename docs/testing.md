# Testing without AI inference

Owner decision, 2026-11-02: automated tests, CI and acceptance must not call a
live AI agent or consume inference tokens. They need no AI account, model login
or AI service credentials. Live gameplay is separate and requires an explicit
owner request; it is not a merge or tracker-completion requirement.

The existing tests exercise the application without a model:

- `tests/fixtures/fake_codex.py` emits scripted CLI events and replies for runner
  tests, including failures, timeouts and subprocess cleanup.
- `tests/fixtures/scripted_referee.py` runs scripted bridge calls and emits a
  structured reply through the real runner. It launches Python, not Codex.
- Host, CLI and browser tests inject scripted Python referee executors. They use
  real temporary databases, local sockets, clients and Chromium where appropriate.
- The referee CLI diagnostic test places the Python fake on its own `PATH`, so
  even version and login-status checks do not use an installed Codex executable.

The tokens generated by authentication tests are temporary Tesserae credentials.
They authenticate local players and bridge calls; they do not access an AI
service. Keep this coverage.

## Running checks

In a virtual environment with `pip install -e '.[dev]'`:

```sh
python3 -m ruff check .
python3 -m ruff format --check .
python3 -m unittest discover -s tests -v
```

For browser coverage, install `.[dev,browser-test]` and Chromium with
`python3 -m playwright install chromium`, then run:

```sh
TESSERAE_BROWSER_TESTS=1 python3 -m unittest discover -s tests -v
```

## Acceptance

M2-3's mixed CLI/browser acceptance (#117) must use scripted referee input/output
through the real runner and bridge, with original public fixtures. It should
exercise creation, approval, play, retries, privacy and cleanup with real clients,
while needing no live AI process, account or login.

Record that the referee was scripted and the exact fixture and application
commits. This validates application integration and routing, not a model's
judgment or storytelling. Past acceptance reports that used a real model remain
unchanged historical evidence and must not be treated as instructions to launch
one again.
